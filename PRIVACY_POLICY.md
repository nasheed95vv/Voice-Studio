# Политика конфиденциальности Voice Studio

Дата вступления в силу: 01.10.26

## Коротко

Voice Studio — полностью офлайн-приложение. Мы не собираем, не передаём и не храним
никакие данные пользователя за пределами его собственного устройства. У приложения нет
серверов, аккаунтов, аналитики и рекламы.

## Какие данные обрабатывает приложение

### Аудиозаписи
Voice Studio записывает звук с микрофона устройства только по явному действию
пользователя (нажатие кнопки записи). Записи сохраняются исключительно в локальном
хранилище приложения на устройстве пользователя (`/data/data/<package>/files/recordings`)
и никогда не передаются за пределы устройства без явного действия пользователя
(экспорт, функция "Поделиться").

### Настройки и метаданные
Названия записей, длительность, папки, теги и пользовательские настройки (тема,
качество записи и т.д.) хранятся локально в базе данных приложения (Room/SQLite) и
в DataStore Preferences. Эти данные не покидают устройство.

### PIN-код и биометрия
Если пользователь включает блокировку приложения, PIN-код хранится не в открытом виде,
а как SHA-256 хэш внутри `EncryptedSharedPreferences`, дополнительно зашифрованного
через Android Keystore (AES-256-GCM). Биометрические данные (отпечаток пальца, лицо)
обрабатываются полностью на уровне операционной системы Android (Biometric API) —
приложение никогда не получает доступ к самим биометрическим данным, только к
результату проверки "успешно/неуспешно".

## Разрешения приложения и зачем они нужны

| Разрешение | Зачем |
|---|---|
| `RECORD_AUDIO` | Запись голоса — основная функция приложения |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MICROPHONE` | Продолжение записи, когда экран выключен или приложение свёрнуто |
| `POST_NOTIFICATIONS` | Уведомление о идущей записи с кнопками паузы/остановки |
| `USE_BIOMETRIC` | Разблокировка приложения по отпечатку/лицу (если включено пользователем) |
| `WAKE_LOCK` | Не даёт системе прервать запись во время работы |
| `WRITE_EXTERNAL_STORAGE` (только Android 8-9) | Сохранение экспортированного файла в публичную папку "Музыка" — запрашивается только при попытке использовать эту функцию, не при установке |

Приложение **не запрашивает** доступ к интернету, контактам, местоположению, камере
или файлам за пределами собственной папки экспорта.

## Отсутствие серверной инфраструктуры

В приложении сознательно отсутствует разрешение на доступ в интернет
(`android.permission.INTERNET`). Это означает, что даже теоретически ни одна часть
приложения не может отправить данные на сервер — не потому что мы обещаем этого не
делать, а потому что технически это невозможно на уровне операционной системы.

## Хранение и удаление данных

- Удалённые записи перемещаются в корзину и хранятся там до истечения срока (настраивается
  пользователем: 7/30/90 дней или бессрочно), после чего удаляются автоматически.
- Пользователь может удалить запись окончательно в любой момент вручную.
- Удаление приложения полностью стирает все данные приложения с устройства
  (стандартное поведение Android для данных в приватном хранилище приложения).

## Данные третьих лиц

Приложение не использует сторонние SDK для аналитики, рекламы или отслеживания.
Список используемых открытых библиотек — в файле `THIRD_PARTY_NOTICES.txt`.

## Дети

Приложение не предназначено для сбора персональных данных детей и не собирает никаких
персональных данных в принципе, поскольку не имеет серверной части.

## Изменения политики

При существенных изменениях в обработке данных актуальная версия этого документа будет
опубликована в приложении и/или на странице приложения в магазине приложений.
